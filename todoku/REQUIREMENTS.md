# とどく 要件定義 v1.0

## 概要

世帯の状況を3問（またはペルソナ1クリック）で聞き、東京都の支援制度オープンデータと突合して「今届く制度」を適合度順に返す。探すのではなく届ける。

都知事杯オープンデータ・ハッカソン2026 提出作品（テーマあり）。

## 確定事項

| 項目 | 内容 |
|------|------|
| サイト名 | **とどく** |
| 公式テーマ（主） | 生活：家庭の状況や困りごとに応じた、手当・助成などの支援制度や福祉サービスの案内 |
| 公式テーマ（副） | デジタル：個人や世帯の状況に応じて、手続や支援制度などの情報が自動的に届く仕組み |
| ユーザー | 都内在住で、手当・助成・福祉サービスの取りこぼしを避けたい世帯 |
| 技術スタック | Next.js 16 / TypeScript / Tailwind CSS 4 / 静的JSON |
| ホスティング | 静的エクスポート（Cloudflare Pages 想定） |
| 判定 | ルール＋スコア。生成AIは使わない（任意拡張） |

## MVP機能

- [x] ペルソナ3種（ひとり親／共働き幼児／介護世帯）のワンクリック投入
- [x] 世帯3問フォーム（家族・世帯の形・家計）
- [x] 制度カード一覧（適合度％、マッチ理由、手続URL、推定時短、年間手取り目安）
- [x] 届く制度の件数・時短・手取りのサマリー
- [x] 条件が近いが対象外の制度（参考）
- [x] データ出典とデモ免責の明示

## 非機能要件

- [x] レスポンシブ（モバイル〜デスクトップ）
- [x] 個人情報をサーバーに送らない（ブラウザ内判定）
- [x] カタログ掲載データを模した静的マスタ（許諾待ちを避ける）
- [x] lint / build が通ること

## スコープ外（今回やらない）

- ログイン・申請代理・マイナポータル連携
- 区市町村ごとの所得制限の厳密計算
- 地図 UI
- 生成AIチャット（コア判定はルール）
- 本番の全制度網羅
