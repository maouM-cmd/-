## 1. 要件定義

### 1.1 目的

既存カップルの「いつものデート脚本」を、店リストではなく **制約1動詞** で壊す。  
半数のチームが作る「AIがデートプランを出すチャット」とは別物にする。

### 1.2 コア体験（Q1）

開いた瞬間に動詞1語のカードが出る。押す（またはワンクリック例）だけで「破った」証拠が載り、AIが審判として一言返す。

- コア動詞: **破る**
- AIの役: **審判 / 実況**。プランは出さない。チャット商品にしない
- 通過の1拍: カード出現 / 破る / 証拠 / 判定スラム

### 1.3 利用者と制約

- 審査員のデスクトップ。カメラ・マイク任意（拒否でも完走）
- 入力欄を埋めてから開始してはならない
- 認証なしで `/` が本体
- ローカルは **PORT=3002**（coupon-board=3000、optimal-match=3001）

### 1.4 機能要件

必須（時間切れでも残す）

- 起動直後に動詞カード（テキスト入力不要）
- ワンクリック例 3枚で人手入力なし完走
- 「破った」ボタンで証拠を載せる（テキスト1行で足りる。写真は任意）
- AI判定 `/api/verdict`（7秒タイムアウト、先に fallback、後から差し替え）
- `/api/health` が `{"status":"ok"}`
- 判定結果の巨大表示（S/A/B/C は「脚本を破れたか」だけ。店の fancy さは採点しない）

後回し

- 2人セッション / 秘密カード
- 履歴の可視化
- 位置情報
- 写真必須

捨てる（作ったら要件違反）

- チャット欄、3プラン提案、Maps埋め込み、店リスト、好みヒアリング、予算フォーム
- optimal-match のフォーク、detohimajikann の流用
- マイク必須、カメラ必須、ログイン必須

### 1.5 受入条件

1. `http://localhost:3002` を開いて 10秒以内に動詞カードが見える
2. 例スロット1発 → 破った → 判定まで、キーボード入力なし
3. Gemini が死んでも fallback 文言で完走。バッジが `AI FALLBACK` になる
4. 画面にチャット入力も Maps も店一覧も無い
5. `npm run lint` と `npm run build` が通る
