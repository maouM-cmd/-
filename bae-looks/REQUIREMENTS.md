# bae-looks 要件定義 v0.1

## 概要

推し活で「動画のベイが着ているもの」を特定する体験を、NMIXXベイ一人に絞ってフロントで検証する。

## 確定事項

| 項目 | 内容 |
|------|------|
| 目的 | 一時停止→スクショ→画像検索の代替UXを体感できること |
| ユーザー | NMIXXベイのファン / 推し活ユーザー |
| 技術スタック | Next.js 16 + React 19 + Tailwind 4（静的モック） |
| ブランド名 | BAE FRAME |

## MVP機能

- [x] ベイ特化ランディング（フルブリードヒーロー）
- [x] サンプルモーメント選択 → 特定デモ → 候補提示
- [x] 確証度バッジ + 購入導線プレースホルダ + プチプラ代替

## 非機能要件

- [x] レスポンシブ対応
- [x] モーションは2〜3種（rise / scan / card stagger）
- [x] 実写肖像を使わず抽象フレームで表現

## スコープ外（今回やらない）

- 実AI物体検出・Vision API接続
- 実EC在庫・アフィリエイト本番契約
- ベイ以外のメンバー / 他アーティスト
- ブラウザ拡張・ライブ連携

## 未決事項

- 拡張時の最初の追加対象（同グループ他メンバー vs 他アーティスト）
- 収益化（アフィリエイト / サブスク）の優先度
