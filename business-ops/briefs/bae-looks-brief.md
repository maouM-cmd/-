# Bae Looks — プロジェクトブリーフ

| 項目 | 記入 |
|------|------|
| プロジェクト名（slug） | bae-looks |
| タイプ | nextjs |
| 一言説明 | NMIXX ベイ特化の「動画フレームから着用アイテムを特定」フロント試作 |

## 目的・ユーザー

- **誰のため:** NMIXX ベイの推し活で、動画の衣装・アクセが気になるファン
- **何を解決する:** 一時停止→スクショ→画像検索の煩雑さを、デモUIで体感できる体験に置き換える
- **成功の定義:** フロントの第一印象が良く、「他メンバー/他タレントへ拡張したい」と判断できること

## MVP機能（3つまで）

1. ベイ特化ランディング（ブランドヒーロー）
2. サンプル動画モーメント選択 → 特定アニメーション → 候補アイテム提示
3. 確証度バッジ付き商品カード（完全一致 / 同一ブランド / 類似）と購入導線プレースホルダ

## 技術選定

| 項目 | 選択 |
|------|------|
| フレームワーク | Next.js 16 + React 19 + Tailwind 4 |
| DB | なし（静的モックJSON） |
| ホスティング | 未定（今回はローカル確認のみ） |
| 参考プロジェクト | optimal-match |

- ベイ以外のメンバー / 他アーティスト展開
