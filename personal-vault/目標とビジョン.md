# 目標とビジョン

> 短期・長期ゴール、「最強AIエージェントマスター」の具体像。

## 事実

### 最強AIエージェントマスター（対話で具体化）

**リポジトリ上の定義:** 人間は判断だけ。実装・文案・調査・定型作業はエージェントに任せる。

**本人の最終ゴール（対話より）:**

1. エージェントが**自立的に一通りの工程を完遂**すること
2. 指示する人間も、**AIが何をしたのか理解できているか**をちゃんと確認できること — **理解の質**が目的の一部

### ハッカソン・社会課題（対話より）

- **社会課題**を解決していきたい
- 具体テーマ:
  - SNSの**過度な誹謗中傷**
  - **ドーパミン刺激**（スクロール依存）への対策 — 無駄な時間を浪費しない設計
- **自分で思いついたものを作って証明**したい（[[価値観]] の「見返す＝目に見える成果」と接続）

### なりたい姿（価値観より）

- 自分のことを**自信を持って語れる**人間になる

### 現在地（AI_AGENT_MASTERY より）

| 項目 | 状態 |
|------|------|
| レベル | L3（autopilot 全自動投稿） |
| ボトルネック | 新しい成果物のゼロイチ |

### ロードマップ（リポジトリより）

```
[今] 手動でCursorに指示 → GitHub手動投稿
  ↓
[Phase 1] Skill + スクリプトで型を固定
  ↓
[Phase 2] 新規プロジェクトを5分で立ち上げ
  ↓
[Phase 3] GitHub投稿を半自動（preflight + 文案生成）
  ↓
[Phase 4] エージェントに任せる範囲を拡大（人間は判断のみ）
```

## 解釈

- **2つの並行ゴール:**
  - **業務:** エージェントが工程を完遂し、人間は理解と判断に専念
  - **ハッカソン:** 社会課題（SNS誹謗中傷・スクロール浪費）をプロダクトで証明
- エージェントマスターの本質は「任せっぱなし」ではなく、**完遂 + 人間の理解**の両立
- ハッカソンとエージェント活用は「**自分のアイデアを形にして示す**」という点で共通（表面的成果への志向は [[価値観]] と一致）
- SNSプロダクトは「使わない」ではなく**スクロールして無駄な時間を浪費しない設計** — 制限より設計で解く志向

## 具体例

- **ハッカソン案:** 誹謗中傷対策、ドーパミン/スクロール浪費を防ぐSNS設計
- **エージェント目標:** 調査→実装→検証の一連を自律完遂 + 人間が内容を理解して承認
- **業務:** Dify / RAGAS 案件で AI 出力の検証経験 → エージェント理解の重要性を実感している可能性
