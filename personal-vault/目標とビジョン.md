# 目標とビジョン

> 短期・長期ゴール、「最強AIエージェントマスター」の具体像。

## 事実

### 最終ゴール（仮置き — BUSINESS_MAP より）

**最強AIエージェントマスター** — 人間は判断だけ。実装・文案・調査・定型作業はエージェントに任せる。

### 現在地（仮置き — AI_AGENT_MASTERY より）

| 項目 | 状態 |
|------|------|
| レベル | L3（autopilot 全自動投稿） |
| ボトルネック | 新しい成果物のゼロイチ |

### ロードマップ（仮置き）

```
[今] 手動でCursorに指示 → GitHub手動投稿
  ↓
[Phase 1] Skill + スクリプトで型を固定
  ↓
[Phase 2] 新規プロジェクトを5分で立ち上げ
  ↓
[Phase 3] GitHub投稿を半自動（preflight + 文案生成）
  ↓
[Phase 4] エージェントに任せる範囲を拡大（人間は判断のみ）
```

### 対話から追加（価値観・考え方より）

- **ハッカソン出場** — 努力を目に見える成果にするための決断（[[価値観]] 参照）
- **なりたい姿** — 自分のことを自信を持って語れる人間になる
- **ハッカソンの方向性** — 社会課題の解決（例: SNS使いすぎ・ドーパミン刺激）、日常課題を自分で思いついて作り、証明する（[[考え方]] 参照）

## 解釈

- 「最強AIエージェントマスター」は**業務・自動化**のゴール。ハッカソンは**社会課題×自分のアイデアを形にする**ゴール — 両方が並行して存在する
- SNS・ドーパミン問題は、自身も実感している身近な社会課題 → 記事・プロダクトのテーマ候補にもなりうる

## 具体例

- **ハッカソン:** SNS過多・ドーパミン刺激への対策プロダクト、日常課題の自作アプリ
- **業務ゴール:** エージェントマスターとして判断のみ人間、実装は任せる（`AI_AGENT_MASTERY.md`）
