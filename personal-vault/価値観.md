# 価値観

> 譲れないこと、嫌なこと、尊敬する姿。

## 事実

### 「見返す」とは何か

- 結論として**目に見える成果を出すこと**
- 裏方でどんなに新しい情報を押していったり努力していても、**人は過程を見てくれない。表面だけしか見てくれない**という実感がある
- そのため、努力が形になる**ハッカソンへの出場**を決めた

### 譲れないこと

- **誠実に生きること**
- **自分に嘘をつかない**
- **過去に嘘をつかないような人間**になりたい

### 尊敬する人 — おじいちゃん

- お酒も飲めないのに、たくさんの人脈がある
- めちゃコミュ力がある

#### おじいちゃんから受け取った3つのこと

1. **幽霊はいない**
   - ちゃんと見れば、ものが視覚としてぼやけていたり、**脳の錯覚**だと仰っていた
2. **お酒には気をつけろ**
   - おじいちゃんも飲めなかった → 孫の自分にも気をつけて欲しいという伝言だったのかもしれない
3. **自分のやりたいことをやって欲しい**
   - （音声入力: 「やりったいこと」→ やりたいこと）

### 自分の課題認識

- **芯がなく**、人に合わせてしまう傾向がある
- **いい人ぶってしまう**

### なりたい姿

- **自分のことを自信を持って語れる**ような人間になりたい

## 解釈

- [[成り立ち]] の「見返す」動機は、恋愛面だけでなく**可視化された成果への欲求**としてより明確になった
- 内的努力（学習・情報収集）と外的評価（人が見る表面）のギャップを痛感している → ハッカソンは「過程ではなく成果で示す」ための具体行動
- **誠実さ**は他者への誠実さだけでなく、**自分に嘘をつかないこと**（いい人ぶらないこと）にもつながる
- おじいちゃんは「お酒がなくても人脈とコミュ力を築ける」存在 — **芯のある本物の人間関係**のモデル
- **教え①** は [[考え方]] の誠実さ・現実を見る姿勢と接続 — 見えないものに逃げず、ちゃんと観察して判断する
- **教え②** はおじいちゃん自身の経験からの**体験的な警告**。酒に頼らず人脈を築けた人が、逆に酒を戒めている
- **教え③** は [[目標とビジョン]] のハッカソン・社会課題への挑戦と直結 — 他人の目より、自分のやりたいことをやる
- 今の自分（合わせる・いい人ぶる）と理想（自信を持って語る）のギャップが、成長のテーマになっている

## 具体例

- **ハッカソン出場** — 努力を目に見える形にするための決断
- **おじいちゃん** — 酒に頼らず人脈を築くコミュ力の具体例
- **おじいちゃんの教え** — 錯覚を疑う / 酒を戒める / やりたいことをやる
- **いい人ぶる傾向** — 誠実さの価値観と矛盾すると感じている部分（改善したい点）
