# 成り立ち

> 幼少期から現在までの経歴・転機・影響を受けた人・出来事。

## 事実

### 時系列（Web開発 / AI領域への流れ）

1. **就活** — 特に強い動機はなく「なんとなく」就職活動をした
2. **入社** — 会社に入社
3. **AI駆動開発への方向づけ** — 入社後、AI駆動開発について勉強するよう促された
4. **現案件** — NS研究室 × NTTドコモの**施策レコメンド**案件に配属

### 現在学んでいる技術・領域

- **プラットフォーム・インフラ:** Dify, Docker, AWS
- **AI / LLM:** 生成AI, ローカル LLM, エージェント開発
- **RAG 系:** RAG, RAGAS
- **基礎:** 基本的な情報知識全般

## 解釈

- 就活時点では明確なキャリアビジョンがなく、**入社後の環境・指示**が現在の方向性（AI駆動開発）を形づけた可能性が高い
- 「幅広く学ぼうとしている」姿勢 — 案件に必要な技術を横断的にキャッチアップしている段階
- Web開発（リポジトリ上の主業務ラベル）と、実際の学習領域（AI・インフラ・RAG）が重なりつつある

## 具体例

- **案件:** NTTドコモ向け施策レコメンド（NS研究室との取り組み）
- **学習の幅:** 単一技術に絞らず、Dify から RAGAS、ローカル LLM まで横断的に触っている
