# 成り立ち

> 幼少期から現在までの経歴・転機・影響を受けた人・出来事。

## 事実

### 時系列（Web開発 / AI領域への流れ）

1. **就活** — 特に強い動機はなく「なんとなく」就職活動をした
2. **入社** — 会社に入社
3. **AI駆動開発への方向づけ** — 入社後、AI駆動開発について勉強するよう促された（当時の感情: **ワクワク**）
4. **現案件** — NS研究室 × NTTドコモの**施策レコメンド**案件に配属

### 現在学んでいる技術・領域

- **プラットフォーム・インフラ:** Dify, Docker, AWS
- **AI / LLM:** 生成AI, ローカル LLM, エージェント開発
- **RAG 系:** RAG, RAGAS
- **基礎:** 基本的な情報知識全般

### 施策レコメンド案件での担当（ワークフロー）

1. 中間マニュアルを作成
2. **Dify** で回答を生成
3. **RAGAS** で検証

### 自分を形づくった環境

- 好きな人に振られてばかりの経験がある
- 「見返そう」と思う動機づけになっている面がある
- 何かに集中していないとメンタルが持たない環境・性質

## 解釈

- 就活時点では明確なキャリアビジョンがなく、**入社後の環境・指示**が現在の方向性（AI駆動開発）を形づけた
- AI駆動開発の学習指示に対して**ワクワク**と感じた — 義務感より好奇心・期待が先だった可能性
- 就活当時と比べて**めちゃ成長している**実感があり、特に**行動力**がずば抜けて違うと自覚している
- 恋愛面の挫折経験が「見返す」モチベーションの一つになっている（詳細は [[価値観]] で深掘り予定）
- **集中しているときにこそ安定する** — 仕事・学習への没入がメンタル維持にもつながっている可能性
- Web開発（リポジトリ上の主業務ラベル）と、実際の学習・業務領域（AI・インフラ・RAG）が重なりつつある

## 具体例

- **案件:** NTTドコモ向け施策レコメンド（NS研究室との取り組み）
- **日々の作業:** マニュアル整備 → Dify 回答生成 → RAGAS 検証のサイクル
- **学習の幅:** 単一技術に絞らず、Dify から RAGAS、ローカル LLM まで横断的に触っている
- **変化の実感:** 「なんとなく就活」していた頃から、行動力が大きく変わった
