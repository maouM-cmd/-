# INBOX

ここに Dify から書き出したファイルを置く。

```
ops-dx/INBOX/
  dsl/     アプリの DSL YAML（必須）
  kb/      INC-01.md などナレッジ本文（必須）
  runs/    最後の実行のコピー（任意）
  DESIGN.md / ROADMAP.md（任意）
```

## DSL の書き出し（1分）

1. https://cloud.dify.ai/apps で対象アプリを開く
2. オーケストレート
3. 右上メニュー → 「DSL をエクスポート」
4. できた YAML を `ops-dx/INBOX/dsl/` に置く

Chatflow と Workflow はアプリごとに1ファイル。
